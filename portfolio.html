Public Projects & Code

NCRIF/Specter
Language: Python / Category: Recon & Scanning

An active port scanner and subdomain enumerator built using Python's asyncio. It is designed to handle heavy concurrent TCP traffic to map out attack surfaces quickly, keeping its focus on speed during initial host discovery.

X3r0Day/XeroDay-APISniffer
Language: Python / Category: OSINT

A scanner utility that automates searching public GitHub repositories. It monitors commits for accidentally leaked API keys, authentication tokens, and credentials so they can be rotated before being abused.

X3r0Day/InformationDisclosure
Language: Python / Category: Web Archive Analysis

A command-line script that queries the Web Archive's CDX database. It parses historical indexes of target domains to identify forgotten directory paths, backups, or configuration files that are no longer accessible on the live web.

X3r0Day/WebShame
Language: Python / Category: Web Auditing

A basic auditing tool that checks targeted servers for missing security response headers, weak SSL protocols, and exposed directories to point out baseline defensive oversights.
